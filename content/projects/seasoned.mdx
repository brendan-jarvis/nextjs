## Original Version (Dev Academy group project, September 2022)

The final group project as part of the Dev Academy course. Built with React and Redux. Hosted on Railway (originally on Heroku).

## Rebuild (T3 Stack, May 2023)

I rebuilt this project solo to learn the T3 stack (TypeScript, Tailwind, tRPC, and Prisma). It also used the unstyled component library of [shadcn/ui](https://ui.shadcn.com/).

I also used this project to improve my skills with Python. The data was collected, cleaned, and stored in a database using BeautifulSoup, Pandas, and Python scripts.

The current version hosted at the link above is the T3 Stack rebuild. The original React/Redux version is no longer online.
